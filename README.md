# 王博晋升之路 · 跑酷 🏃

给王博定制的横版跑酷小游戏。点击跳跃、下滑铲人,在越来越快的仕途上躲开诱惑,从科员一路升到厅长。被抓进局子之前,能撑多久?

> 网页版、安卓 / iOS(Capacitor)、桌面端(Tauri)、微信小游戏四端同源。

## 一分钟上手

| 操作 | 手机 | 键盘 |
| --- | --- | --- |
| 跳跃 / 二段跳 | 点击屏幕(长按跳更高) | 空格 / ↑ / W |
| 滑铲 | 屏幕下半区点按、向下滑 | ↓ / S |
| 射击 | 右下角「射击」按钮 | J |
| 贿月护体 | 右下角「贿月」按钮 | 点击按钮 |
| 暂停 | 右上角暂停 | ESC / P |

- 初始 2 条命,商店可解锁额外生命;被抓后短暂无敌并减速。
- 存活 30 秒解锁**二段跳**,30 秒后 BGM 自动切换。
- 微信小游戏里被抓后可**分享复活一次**;网页版直接结算。

## 这一版新增了什么

### 1. 滑铲 + 低空美女
地面障碍要跳,低空飞来的美女要滑铲钻过。滑铲时碰撞箱只有 48px 高,站姿一定会撞头。

### 2. 擦身而过 + 气势 + 高光时刻
贴着障碍躲过会触发「擦身」,额外银币和气势。翻越、吃币、擦身、击杀都会攒气势;气势满槽自动进入**高光时刻**:短暂无敌、撞碎障碍、银币翻倍。

### 3. 单局官阶
每翻越一定数量的障碍,本局官阶晋升一次:

`科员 → 副科长 → 科长 → 副处长 → 处长 → 副局长 → 局长 → 厅长`

升官时有专属横幅、音效和 +5 银币。生涯称号(按累计翻越数)和单局官阶互相独立。

### 4. 本局考核
每局随机抽一个短目标:翻越、存活、拾取、连击、擦身、击毁、无伤。完成后立刻发银币,结算页会展示是否完成。

### 5. 每日挑战
每天固定随机种子 + 一条今日规则(极速晋升 / 红包雨 / 巡视风暴 / 一命通关)。每天首次完成 +40🪙,破当日纪录再 +40🪙。标题页直接进入,结算后可以保持今日挑战再来一局。

### 6. 更完整的反馈
- 新 HUD:生命、银币、官阶进度、计时、气势条、本局考核、每日规则
- 视差城市、日月、昼夜循环、夜色 / 高光 / 巡视滤镜
- 升官、擦身、高光、连击、金币、道具都有独立音效与粒子反馈
- 全新标题页、商店、任务/成就/排行、设置、自定义人物、顾哥商铺
- 结算页支持**保存战绩卡**(1080×1440 PNG)分享

## 我的家(可走动的小家模式)

- 主角在客厅里自由走动(`A/D` / 方向键),手机端有 ◀ ▶ E 虚拟按钮;靠近家具或客人按 `E` 交互。
- **产业 = 家具**:小金库、情妇别墅、关联公司、干股煤矿、海外账户、学区房炒房团,置办后摆进屋里,等级越高底座越讲穷、暖光越亮。
- **人脉 = 屋里的客人**:退休老领导、秘书小王、财务老李、巡视组熟人、组织部长,各染一色站在客厅,熟络后会有台词。
- **两套钱分开记账**:
  - **银币**(跑酷 / 横版挣的明面收入):首次置办产业、结交人脉、商店消费。
  - **黑金**(产业产出的赃款):升级产业、打点纪检委、洗白账目;洗白还能把一部分赃款洗成明面银币。
- **走路捡钱**:客厅每 7.6 秒掉一小堆黑金,走过去自动捡 —— 主动玩比干等产出快约 60%。
- **随机事件**:上门送礼的老板(收下得黑金,但按净风险掷一次审查)、每天第一次进屋的「土特产」快递箱。
- **被查**:每 2 分钟按净风险掷骰,弹窗选「打点」(花黑金必过)或「硬扛」(赌运气)。
- **房间豪华度**:家产总值分 5 档,地板、地毯、壁灯、水晶吊灯、窗外灯火逐档升级;风险 ≥80 时屏幕泛红。
- **跑路上岸**:家产到 6 万可清盘换「海外身份」,每级永久 +25% 产出,银币与闯关进度保留。
- 屋里还有一台电视播本市新闻、官场名人堂(与 7 位对手比家产)、一键晒家产卡。

## 系统一览

- **障碍**:金条、红包、财宝、美女 ×4,以及低空飞来的美女;全部使用项目素材 / 程序化贴图。
- **银币**:翻越 +1,低空美女 +2,击毁 +1;连击 ×10 加倍、×25 三倍。
- **空中道具**:🪙 银币袋 / 🛡 临时护盾 / 💰 双倍银币 / 🐢 缓刑减速 / ⚡ 气势暴涨。
- **巡视组**:随机来袭,障碍密度提升,撑过 10 秒有额外奖励。
- **商店**:反腐手枪(3/5/7 发)、弹容量升级、贿月扩容、6 种挂件、4 套皮肤、初始生命升级。
- **顾哥神秘商铺**:500🪙 购买贿月,使用后挡一次伤害。
- **每日任务 + 签到**:翻越 / 存活 / 击毁 / 拾取,全完成领 120🪙;每日签到 +20🪙,连续 7 天额外 +100🪙。
- **成就**:21 项成就,打开成就页自动补发奖励。
- **存档**:本地自动保存,支持设置页导出 / 导入文本;老存档自动补齐新字段,银币不丢失。
- **排行榜**:微信小游戏版使用开放数据域展示好友最佳存活。
- **自定义人物**:上传照片、裁剪头部,游戏内和结算页同步换脸。

## 技术栈

- [Phaser 3](https://phaser.io/) + TypeScript + Vite
- [Capacitor](https://capacitorjs.com/) 打包安卓 / iOS(安卓已锁横屏 + 防息屏)
- [Tauri](https://tauri.app/) 打包桌面端
- 微信小游戏:自研适配层 + 单文件构建 + 开放数据域好友排行
- [Vitest](https://vitest.dev/) 单元测试:存档迁移、成就、每日任务、每日挑战、官阶、考核、Pattern、存档备份、家产养成(双货币 / 洗白产出 / 头衔档位 / 海外身份)

## 本地开发

```bash
npm install
npm run dev          # 本地开发服务器
npm run typecheck    # TypeScript 检查
npm test             # 单元测试
npm run build        # 构建网页版到 dist/
npm run gen:sfx      # 重新生成程序化音效
```

## 打包发布

- **网页版**:`npm run build`,把 `dist/` 部署到任意静态服务器(已配置相对路径与 Service Worker)。
- **微信小游戏**:`npm run build:minigame` → 用微信开发者工具导入 `dist-minigame/`。上传前把 `minigame/project.config.json` 里的 `appid` 换成自己的小游戏 AppID。
- **安卓 / iOS**:`npm run cap:sync`,然后用 Android Studio / Xcode 打开对应工程。
- **桌面版**:`npm run tauri:build`。

## 开发备注

- 所有音效由 `scripts/gen-sfx.mjs` 程序合成,原创无版权风险。
- 游戏逻辑分辨率 960×540,`Phaser.Scale.FIT` 自适应任意屏幕。
- 场景重启会完整重置局内状态;新增局内字段时记得同步 `GameScene.resetRunState()`。
- 自动化截图 / 冒烟脚本在 `.shots/`,使用本机 Chrome + puppeteer-core。
