# 王博晋升之路跑酷 🏃

给王博定制的横版跑酷小游戏:点击屏幕跳跃躲避障碍,**无限生存挑战**,生命归零才结算;被纪检委(鸡煎胃)抓进局子。

## 玩法

- 点击屏幕 / 按空格键跳跃,**按住久跳高、松手小跳**
- **存活 30 秒解锁二段跳**(空中可再跳一次)
- 速度随存活时间持续加快(每 10 秒 +30 px/s,放缓版)
- 第一次被抓:1 秒无敌 + 减速,第二次被抓:游戏结束
- 最佳成绩自动保存在本机

## 障碍物(贪官路上的诱惑)

金币堆 / 红包雨 / 财宝 / 美女 ×4(半空还会飞来美女)—— 全部为作者提供的图片素材,已去背景处理

## 成长系统(本地存档)

- **银币**:每翻越一个障碍 +1🪙,晋升成功额外 +5
- **称号**:按累计翻越数自动晋升 —— 科长(50)→ 处长(150)→ 局长(300)→ 厅长(500)
- **商店兑换**:🛒 晋升商店
  - 🔫 反腐手枪(30🪙):每局 3 发子弹,射击摧毁障碍(点右下角按钮 / 按 J 键)
  - 挂件(25~60🪙):头顶 ⭐ / 💼 / 👑

## 素材

- 玩家角色:作者自制的像素角色照片,裁剪去背景后生成精灵图
- 障碍物:程序生成的像素贴图(百元大钞、金条、公文包)
- 玩法手感参照 Chrome 恐龙跑酷的公开参数(重力、跳跃初速、短跳机制),无第三方美术素材

## 技术栈

- [Phaser 3](https://phaser.io/) 游戏引擎 + TypeScript + Vite
- [Capacitor](https://capacitorjs.com/):安卓 / iOS 打包
- [Tauri](https://tauri.app/):桌面版打包(macOS 已可出包)
- GitHub Actions:每次推送自动部署网页版、自动打包安卓 APK

## 本地开发

```bash
npm install
npm run dev        # 浏览器打开游戏
npm run build      # 构建网页版到 dist/
```

## 打包

- **安卓 APK**:推送代码后 GitHub Actions 自动打包,并发布到 GitHub Release(带 APK 下载)
- **微信小游戏**:`npm run build:minigame` → 用微信开发者工具导入 `dist-minigame/` 目录,上传体验版
- **桌面版**:`npm run tauri:build`

## 目录结构

```
src/
  scenes/        Boot → Preload → Game → Result 四个场景
  config/        游戏参数常量(速度、跳跃、障碍等)
android/ ios/    Capacitor 移动端工程
src-tauri/       Tauri 桌面端工程
.github/workflows/  网页部署 + APK 打包工作流
```
